# Metis 项目目标

Metis 是面向任务专用模型的 SystemOne 后训练工具包。它把输入、监督信号、目标和评价指标明确的任务，训练成可独立评估、导出和调用的模型模块。排序、列选择、分类与路由是可能的任务；NFCorpus 是首个 cookbook，不限定工具包范围。

## 五条主线

1. 任务定义：描述输入、候选、监督、损失、指标与最终决策。
2. 架构与算子：定义候选间可见性、逻辑位置、mask 和可复用执行方式。
3. 框架契约：组织数据、配置、训练、恢复、导出、加载和部署接口。
4. 张量教学：把 token、Q/K/V、mask、RoPE、readout、loss 和梯度与代码对应起来。
5. Cookbook 与 Agent：提供公开数据的真实训练、留出评测、可加载产物和工具调用示例。

Qwen base + 独立 ScoreHead 是一种重要适配；yes/no 读出可作为另一种 adapter。任务可以使用 BCE、CE 或排序损失，并不要求全部转成聊天式 next-token SFT。

## 模型在 Agent 系统中的位置

通用 LLM 负责灵活推理与生成；workflow/harness 管理编排、环境交互、解析和记录；Metis 模型提供稳定、可单独验证的评分、选择或分类能力。

## 证据边界

软件实现、软件测试、真实参数更新和任务质量是不同证据。tiny 模型与接口测试不能代表真实任务质量。dense mask 定义可见性，但不自动带来稀疏执行加速。pairs 与 tree 在相同 token、位置和权重下的等价也不表示 tree 会提升任务质量。所有公开结果均应说明模型、数据、评估协议与限制。
