# Metis · 墨提斯

项目、代号与仓库统一使用 **Metis**，中文名为 **墨提斯**。Python 包、安装包和命令行使用小写 `metis`，运行库位于 `src/metis/`。

Metis 得名于希腊神话中的墨提斯，也是木星的一颗卫星。2026-09-27 选定名称，拼写与作者的 GitHub 名字 Mortis 呼应；2026-10-04 将代码和命令行统一到这一名称。

项目定位见 [核心约定](core.md)，源码仓库为 [Shichaoxx/Metis](https://github.com/Shichaoxx/Metis)。

历史实验报告、日志、冻结数据和初版 PDF 保留当时名称。当前代码可以读取旧 checkpoint 的 `cometa_resume.json`、`cometa_selection.json`，报告比较工具也兼容旧的源码哈希字段；新输出使用 `metis` 名称。模型格式、compiler 版本和既有产物内容不因改名而更改。
